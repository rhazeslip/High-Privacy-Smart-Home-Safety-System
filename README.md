# High-Privacy Smart Home Safety System

A privacy-focused home security monitoring system that runs entirely on your local network. No cloud services, no data leaving your home.

## Features

- **Local-First Privacy** - All data stays on your home network
- **Real-Time Monitoring** - Door, window, smoke, CO, water, and temperature sensors
- **Secure Authentication** - HTTPS with PBKDF2 + bcrypt password hashing
- **Web Dashboard** - Clean interface accessible from any device on your network

## Quick Start

Setup
```bash
cd %USERPROFILE%\Documents\GitHub\High-Privacy-Smart-Home-Safety-System\
.\setup.bat
```

Start Program
```bash
start.bat
```

Stop Program
```bash
stop.bat
```
